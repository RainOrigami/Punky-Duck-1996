# `OBJETS_n.3D` — 3D objects

Parser: `crates/pd-formats/src/mesh3d.rs`. Dump: `objets_n_obj_KK.obj` + `objets_n.mtl`.

## Layout — **verified** (loader `0x141a0`)

```
u32 object_count      -> 0x4005c
u32 point_count       -> 0x4f0e50   error if point_count*3 > 8400 ("Erreur nb pts dans objets 3d")
u32 face_count        -> 0x4f0e4c   error if face_count*3  > 6500 ("Erreur nb faces dans objets 3d")
u32 unused            read and discarded (0 on disc)
object_count x { u32 first_point, u32 first_face, u32 point_count, u32 face_count }
point_count  x { f32 x, f32 y, f32 z }           -> 0x23d368
face_count   x 24-byte face                      -> 0x1cc508
```

Sizes add up exactly for all five files; objects tile the point and face arrays without gaps.
**verified** (unit test `disc_meshes`). The loader stores each object as
`{first_point, first_point+count-1, first_face, first_face+count-1}` at `0x271b88`.

## Points — **verified**

`f32`, no fixed point. The loader multiplies every coordinate by 2.0 (`0x42457`, loop
`0x1435d`). File +Y points **down**: the renderer negates Y after rotating
(`0x13e77`: `y' = pos.y - 0.24 * y`), and the exported models stand upright only with Y
negated (**verified** by output: raft with mast, huts, plane). X/Z are added to the
instance position unscaled (`0x13e63`, `0x13e93`).

## Face (24 bytes, all `i16`) — **verified** (`0x13f50`, `0x14ef5`)

| Offset | Field |
|---|---|
| 0 | texture index into the `OBJETS_n.MAP` record table |
| 2 | copy of the owning object's `first_point` — not read by the game |
| 4 | 0 — not read |
| 6, 8, 10 | point index of corner 0, 1, 2, **relative to the object's first point** |
| 12, 14, 16 | u (texel column) of corner 0, 1, 2 |
| 18, 20, 22 | v (texel row) of corner 0, 1, 2 |

u/v are whole texels relative to the texture's top-left (`0x4f0af0..8` = u, `0x4f0ae0..8` = v,
same rasteriser variables as the terrain). On disc they stay inside the texture rectangle
except for 8 faces of island 5 that touch `u == width` or `v == height`.

Faces are depth-sorted per frame by the mean of their three projected depths (`0x13f78`),
not by a stored order.

## Placement (not in the file)

Objects are instanced from code: `0x27ec0(slot, x, y, z, object_index, param)` fills a
24-byte table at `0x516ae8`; e.g. island 1 setup at `0x177ad` places object 0 at
(18562, -300, 1687), object 1 at (19724, -300, 5864) … **verified** (calls read), the
meaning of `param` (200..1000) is not established. Rotation: per-instance angles are passed
to `0x156e0` to build the matrix at `0x4f0eec..0x4f0f0c`.

## OBJ export convention

`v` = file value x 2 with Y and Z negated (half turn about X: +Y up, winding kept).
`vt` = `((u+0.5)/w, 1-(v+0.5)/h)` of the face's texture, one material per texture.

Punky Duck: controls, options and cheats

Versions

Choose the version before loading the disc. The choice is remembered.

Original
Behaves like the 1996 DOS release, bugs included. As on the original disc, finishing the first island plays the ending; the other four islands are reached with the level select cheat below or from a saved game.
Enhanced
Modern controls (mouse look, WASD with strafing, fire on the left mouse button, number keys for weapons) and fixes for the original's bugs: finishing island 1 leads on to island 2, the compass survives loading and resuming, monsters keep to their patrol paths, hits are scored by the weapon that fired, spent shots stop hurting monsters, a death costs one life instead of sometimes two, the fifth teleporter pad on islands 3 and 4 works, and the full picture is shown.

Cheats

These are the original game's own cheats and work in both versions.

Level select (the cheat menu)

  1. Open any menu, for example the main menu.
  2. Type THE TRUTH IS OUT THERE in capital letters, with the spaces (hold Shift or turn on Caps Lock). The screen flashes red.
  3. Choose NEW GAME. It now opens the CHEAT MODE menu, where you pick the island to start on: Fisher, Oasis, Yeti, Cold or Smoke Island.

Cheats while playing

Each cheat is three keys held together, with no other key down. First hold H C T once to switch the cheats on. A cheat, once given, stays in force until you reload the page. The screen flashes red each time one is accepted.
